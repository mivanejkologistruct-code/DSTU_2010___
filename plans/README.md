# `plans` Folder

This folder stores the project planning journal.

## Files
- `planned.md` - queue of tasks that have not been finished yet; each entry records the date it was added, a short title, a brief description, and the status (`planned` or `in_progress`).
- `completed.md` - archive of finished tasks; each entry records the completion date, the task title, the delivered result, and the status (`done`).

## Maintenance Rule
- Add a new record to `planned.md` before implementation starts.
- After completion, move the record to `completed.md` and append the completion date and the delivered result.
